## 当前核心方案

- 项目规模：成员 A、成员 B 两人，约两周。
- 技术栈：Vue 3 + Spring Boot 2.7.18 + MySQL 8.0.16+。
- 三个业务模块：气象数据查询、气象数据可视化、基础数据管理。
- 四张核心表：`city`、`forecast_model`、`weather_element`、`forecast_record`。
- 业务唯一键：`(city_id, model_id, element_id, forecast_time)`。
- 演示城市：济南、青岛、烟台、潍坊、临沂、济宁；核心演示使用济南和青岛。
- 核心要素：T2M（℃）、PRECIP（mm）。
- 示例模型：ECMWF、NOAA。
