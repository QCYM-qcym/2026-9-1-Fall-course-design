# 《江苏省气象预报数据可视化系统的设计与实现》

## 项目定位

本项目由成员 A、成员 B 两人协作完成，计划周期约两周。当前以课程设计资料建设为起点，在需求、设计、数据与项目管理资料冻结后，再进入应用实现。

## 核心目标

围绕江苏省气象预报数据，形成可查询、可视化展示与基础数据管理相结合的系统设计与实现资料体系，为后续开发提供统一依据。

## 三大业务模块

- 气象数据查询
- 气象数据可视化
- 基础气象数据管理

## 冻结技术栈

- 前端：Vue 3、Vite、JavaScript、Element Plus、ECharts、Axios、Vue Router
- 后端：Java 8、Spring Boot 2.7.18、MyBatis-Plus、Maven
- 数据库：MySQL 8
