# 系统边界与不做事项 V2

## 1. 核心范围

Weather Workbench、Trend Analysis、Model Comparison、Data Management 四页；山东地图是 P0 核心验收条件。ECharts Map + 静态山东 GeoJSON、16 市、ECMWF/NOAA、T2M/PRECIP。工作台批量查询与前端时间轴切换，趋势双图与简单统计，双模型视觉对比，四类数据完整 CRUD。

唯一参与者为用户，无权限角色。四表与 3NF 不变，不因地图、时间轴、统计增加实体。

## 2. 明确不做

- 登录、用户权限、JWT、Security、Redis、缓存框架、复杂日志或审计系统。
- TDengine、ERA5、NetCDF 在线处理、实时气象采集、Python 服务。
- Leaflet、Mapbox、Cesium、PostGIS、GIS Server、复杂 GIS、风场动画、高空场 / Pressure Level。
- RMSE、MAE、bias、accuracy、多模式演变矩阵、预测模型训练、30 天延伸期。
- 电价预测、新能源出力预测、自动电力交易或自动业务决策。
- DDD、Repository Interface/Impl、微服务、Docker/K8s、生产级部署、高并发与高可用承诺。
- province、region、statistics、dashboard、chart、timeline 等额外业务表。

## 3. UI 参考与版权边界

Windy.com 仅作为地图主视觉、悬浮控件、图层/模型切换、时间轴、图例和点击详情的交互思想参考。不复制其 Logo、图片、图标、CSS、专有视觉素材或页面代码；未来 GeoJSON 须单独核验来源、许可和 16 市覆盖。

## 4. 变更控制

本轮用户明确授权 V2 升级，替代 V1 地图增强项与字典 CRUD 待定状态。后续新需求先记录原因、责任人和对文档、API、数据库、前端、测试及周期的影响，再经用户确认；不得以“优化”扩大两人两周工程量。
