# 系统边界与不做事项

## 1. 核心范围

- 以城市、日期/时间范围、气象要素和预报模型查询山东省城市预报记录。
- 以查询表格、温度折线图和降水柱状图展示结果。
- 维护城市、预报模型、气象要素、预报记录四类基础数据。
- 支持 T2M（2 米气温，℃）、PRECIP（降水量，mm），示例模型 ECMWF、NOAA。

## 2. 增强范围

山东地图可作为城市预报数据的增强展示，用于辅助观察空间分布。其缺失不影响查询、表格、温度折线、降水柱状图和基础管理的验收。

课程设计当前数据范围固定为山东省，因此不单独建立省级行政区表。

## 3. 明确不做

- 不做登录、用户权限、JWT、Redis、Docker、微服务、K8s、生产级部署或高可用、高并发承诺。
- 不做 TDengine、NetCDF 在线解析、ERA5、Pressure Level 或 Python 服务。
- 不做 RMSE、多模式演变矩阵、复杂风场、30 天延伸期。
- 不做电价预测、新能源出力预测、自动交易、自动业务决策。

## 4. 边界判定原则

凡不能直接支持三大业务模块、两周两人课程设计规模或核心验收目标的内容，均不进入本轮实现承诺。新增需求须先更新需求、数据与设计资料，再决定是否纳入后续计划。
