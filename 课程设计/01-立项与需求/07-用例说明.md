# 用例说明 V2

唯一参与者：用户；不划分管理员，无登录授权。沿用 UC-01～05，新增 UC-06～08，均为待实现设计。

| 编号 | 用例 / 需求 | 主流程与后置条件 | 备选流程 |
| --- | --- | --- | --- |
| UC-01 | 管理查询 / FR-Q-01～05、FR-V-01 | 在记录 Tab 可选组合筛选，时间成对；返回有序明细表 | 非法 400；无匹配 200 空数组 |
| UC-02 | 温度趋势 / FR-A-01、02、FR-V-02 | 选城市、模型、范围；trend 同次返回温度、降水；显示折线与最高/最低/平均温 | 温度缺失显示断点和 null 统计 |
| UC-03 | 降水趋势 / FR-A-01、03、FR-V-03 | 与 UC-02 共用 /analysis 和同一响应；显示柱状图、累计降水 | 空降水序列显示暂无数据，不冒充零降水 |
| UC-04 | 字典管理 / FR-M-01～03、05 | 同一页面前三 Tab 完整 CRUD；成功刷新下拉与缓存 | 唯一编码冲突/被引用删除 409；不存在 404 |
| UC-05 | 预报记录管理 / FR-M-04 | 第四 Tab 新增、查询、修改、删除；成功清缓存，重新趋势查询确认变化 | 无效关联 404；非法值 400；业务键冲突 409 |
| UC-06 | 山东工作台 / FR-W-01～04 | 默认 ECMWF/T2M 批量加载 16 市全时段；切换图层/模型；拖动时间轴本地重绘 | Loading、请求失败可重试、空结果或单城缺测，保留地图轮廓 |
| UC-07 | 城市详情 / FR-W-05 | 点击济南/青岛，展示城市、模型、要素、时间、值、单位；携带城市/模型/范围进入趋势 | 无当前时刻值显示暂无数据；有效城市仍可查看趋势 |
| UC-08 | 模型对比 / FR-C-01 | 城市、要素、范围；ECMWF/NOAA 双折线或分组柱状图 | 两模型时刻取并集，缺点为 null；无记录保留空模型系列 |

## 前置条件与共同规则

数据库四表、字典与演示记录由后续初始化任务准备；工作台要求静态地图资源与 cityCode 映射。操作前验证必要参数，不将错误视为空结果。写入成功才清除缓存和显示成功，失败不改变已保存状态。核心演示先济南再青岛；管理演示使用可清理的临时字典数据，不破坏核心模型/要素含义。
