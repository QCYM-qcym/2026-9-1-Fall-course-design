## 2. 查询（保留编号）

- FR-Q-01：城市筛选用于趋势、对比、管理；工作台查询全部山东城市，点击城市不重新查询。
- FR-Q-02：时间范围使用本地业务时间，起止成对、开始不晚于结束，含两端。
- FR-Q-03：要素为 T2M（℃）、PRECIP（mm）；工作台/对比选择单要素，趋势一次返回双要素。
- FR-Q-04：模型为 ECMWF、NOAA；工作台/趋势选择单模型，对比同时返回两模型。
- FR-Q-05：按各接口规定组合条件；非法参数明确提示，无结果显示 Empty，不伪造零值。

## 4. 管理（原待确认冲突已解决）

- FR-M-01：城市完整新增、查询、修改、删除。
- FR-M-02：预报模型完整新增、查询、修改、删除。
- FR-M-03：气象要素完整新增、查询、修改、删除。
- FR-M-04：预报记录完整 CRUD；关联必须存在，业务唯一键重复返回 409。
- FR-M-05：删除被记录引用的字典返回 409，不级联删除；不存在返回 404。
- 四类对象集中于 /management 的四个 Element Plus Tabs，不做四套后台。
- 写入成功后刷新列表、清除工作台内存缓存及相关字典缓存；趋势/对比再次进入或查询时重新请求。

## 5. 气象工作台

- FR-W-01：/ 默认进入 /weather，以 ECharts Map + 静态 GeoJSON 显示山东全部 16 市，地图为最大视觉区域。
- FR-W-02：T2M / PRECIP 图层切换，着色、图例、单位和详情同步。
- FR-W-03：ECMWF / NOAA 模型切换；初始 ECMWF + T2M + 约 7 天演示窗口。
- FR-W-04：一次加载全省指定模型/要素/范围全部时刻，times 升序；拖动 selectedTime 只本地过滤，不产生 API 请求。
- FR-W-05：点击城市显示名称、模型、要素、时刻、数值、单位；“查看趋势”携带 cityId、modelId、startTime、endTime 跳转 /analysis。

## 6. 趋势与对比

- FR-A-01：/analysis 按城市、模型、范围一次展示 T2M 折线与 PRECIP 柱状图、同响应明细表。
- FR-A-02：WeatherQueryService 计算最高、最低、平均温度；空温度序列三项为 null。
- FR-A-03：Service 计算查询范围内的累计降水；空序列为 null，非重叠时段降水量相加，不新增统计表。
- FR-C-01：/comparison 按城市、要素、范围比较 ECMWF 和 NOAA；T2M 双折线，PRECIP 分组柱状；缺测保留间隙，不计算 RMSE / MAE / bias / accuracy。
