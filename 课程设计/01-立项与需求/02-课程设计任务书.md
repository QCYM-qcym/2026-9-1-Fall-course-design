# 课程设计任务书

## 1. 课题与目标

《山东省气象预报数据可视化系统的设计与实现》。两人、约两周，建设功能完整、展示清晰、交互流畅的气象可视化系统。当前任务 SYSTEM-DESIGN-V2 只冻结文档，不创建工程、数据库或接口实现。

## 2. 工作范围

四个页面：Weather Workbench、Trend Analysis、Model Comparison、Data Management。山东地图是 P0；工作台批量加载后在前端切换时间轴；趋势展示双要素与四项统计；模型对比只比较预报结果；四类对象完整 CRUD。

技术栈：Vue 3、Vite、JavaScript、Element Plus、ECharts、Axios、Vue Router；Java 8、Spring Boot 2.7.18、MyBatis-Plus、MyBatis XML、Maven；MySQL 8.0.16+。测试使用 JUnit 5、Spring Boot Test、Postman / Apifox。

## 3. 人员与周期

成员 A、B 协作。原课程日程保持：9 月 3～18 日主要开发、9 月 11 日中检、9 月 18 日软件验收、9 月 25 日材料归档。V2 的中检只要求地图主链路、详情和一个趋势图，完整 CRUD 与 Comparison 可在中检后完成；不把全部 V2 压到中检前。

## 4. 成果物与目录

未来 frontend/ 保存当前 Vue，backend/ 保存当前 Spring Boot，database/ 保存当前脚本；课程设计/ 保存唯一当前文档，versions/ 只保存阶段说明、截图、测试和 Git 信息，不复制整套源代码，不另建重复 docs/ 文档体系。

## 5. 验收依据

需求编号、API V2、四表设计、Canvas 与验收方案保持一致。功能设计冻结不等于已实现，未执行的测试不得标记通过。
