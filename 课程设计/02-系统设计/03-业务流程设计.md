# 业务流程设计

## 1. 流程范围与图示依据

本文描述后续将用于课程演示的两条计划流程：核心查询流程，以及维护一条演示数据后重新查询的验收流程。流程只在气象数据查询、数据可视化、基础数据管理三个模块内流转。数据流层次将对应 [[09-白板/04-DFD-0层数据流图|DFD-0层数据流图]] 与 [[09-白板/05-DFD-1层数据流图|DFD-1层数据流图]]；参与层次与职责将对应 [[09-白板/08-核心查询泳道图|核心查询泳道图]]。

## 2. 核心查询流程：济南 + ECMWF + T2M

该流程验证 Browser → Vue 3 → Axios/REST JSON → Spring Boot → Controller → Service → Mapper（MyBatis-Plus）→ MySQL 8 的既定调用方向。

1. 用户在 Browser 的 Vue 3 页面中选择城市“济南”、预报模型“ECMWF”、气象要素“T2M”，并填写包含演示数据的日期/时间范围。
2. Vue 3 检查四项查询条件是否可提交；若开始时间晚于结束时间或条件缺失，则在页面给出明确提示并停止本轮查询。
3. Vue 3 通过 Axios 发送 REST JSON 查询条件。Spring Boot 的 Controller 接收条件并交给 Service。
4. Service 校验条件后，按济南、ECMWF、T2M 和有效时间范围组合查询；Mapper（MyBatis-Plus）从 MySQL 8 读取匹配预报记录。
5. Mapper 将记录返回 Service，Service 整理为 REST JSON 结果，经 Controller、Axios 返回 Vue 3。若无匹配记录，则返回可供页面显示的空结果提示。
6. Vue 3 使用本轮结果先显示表格，再将 T2M 记录按有效时间排序后交由 ECharts 绘制温度趋势折线图；表格与图表均显示 ℃ 单位。
7. 用户核对表格与折线图的城市、模型、要素、有效时间和温度数值是否来自同一轮结果。该流程映射 FR-Q-01～FR-Q-05、FR-V-01、FR-V-02、FR-V-04、UC-01、UC-02、NFR-C-01。

## 3. 维护后重新查询的验收流程

该流程用于验证基础数据管理与查询、展示之间的衔接；演示前应已有可关联的城市、模型和要素资料。

1. 用户进入基础数据管理，新增或修改一条演示预报记录，填写已存在的城市、预报模型、气象要素、有效时间和数值。
2. Vue 3 将资料提交给后端；Controller 转交 Service。Service 验证关联对象存在、有效时间合法、数值可解析，并检查候选业务键 `(city_id, model_id, element_id, forecast_time)`：新增不得重复，修改只处理对应的既有唯一记录。
3. 校验未通过时，后端将明确原因以 REST JSON 返回，Vue 3 显示提示，且不保存本次内容。校验通过时，Mapper（MyBatis-Plus）向 MySQL 8 保存变更，并将处理结果返回页面。
4. 用户回到查询模块，使用与该记录一致的城市、日期/时间范围、要素和模型重新查询。后端按核心查询流程读取记录，页面更新同轮表格及对应的温度折线图或降水柱状图。
5. 用户确认新增或修改后的数值、有效时间和单位出现在表格与对应图表中；如选择 T2M，核对折线图与 ℃，如选择 PRECIP，核对柱状图与 mm。该流程映射 FR-M-01～FR-M-05、FR-Q-05、FR-V-01～FR-V-04、UC-04、UC-05、NFR-C-02、NFR-S-01、NFR-D-02。

## 4. 验收检查点

- 对核心查询：四项条件均可定位和提交；济南、ECMWF、T2M 的结果同时形成表格与带 ℃ 单位的温度折线图。
- 对降水展示：以覆盖 PRECIP 的演示条件查询，结果同时形成表格与带 mm 单位的降水柱状图。
- 对无结果和非法输入：无匹配条件显示空结果提示；时间范围不合法、关联资料缺失或数值不可解析时，查询或保存被阻止并显示明确提示。
- 对维护后查询：合法新增或修改的一条演示记录可被相同条件重新检索，并在表格和对应图表中保持一致。
- 对兼容性：将在 Chrome 与 Microsoft Edge 中分别完成上述核心查询和无结果查询，确认字段可操作、表格和两类图表可见且没有阻断流程的页面错误提示。

以上检查点对应 NFR-U-01、NFR-U-02、NFR-C-01、NFR-C-02、NFR-K-01、NFR-S-01 与 NFR-D-01～NFR-D-02。需求输入见 [[01-立项与需求/03-需求分析|需求分析]]、[[01-立项与需求/04-功能需求|功能需求]]、[[01-立项与需求/05-非功能需求|非功能需求]]、[[01-立项与需求/07-用例说明|用例说明]]、[[01-立项与需求/08-数据需求|数据需求]]；项目导航见 [[00-项目总览/项目导航|项目导航]]。
