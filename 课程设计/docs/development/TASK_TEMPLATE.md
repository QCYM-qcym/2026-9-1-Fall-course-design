# Codex 任务模板

> 用途：创建前端、后端、数据库、文档或测试任务时复制填写。删除不适用项，避免把多个独立目标塞进同一任务。

## 1. 任务信息

- 任务编号：`<例如 BACKEND-1>`
- 任务名称：`<一句话说明目标>`
- 任务类型：`前端 / 后端 / 数据库 / 文档 / 测试`
- 负责人：`成员 A / 成员 B / 共同`
- 依据文档：`<仓库相对路径>`
- 前置条件：`<必须已经存在或确认的内容>`

## 2. 目标

用一至三句话描述本任务结束时应得到的可验证结果。只写本任务目标，不扩展系统范围。

## 3. 允许范围

- 允许创建：`<路径或文件>`
- 允许修改：`<路径或文件>`
- 允许执行：`<构建、测试、DDL 或检查命令>`

## 4. 禁止范围

- 禁止修改：`<路径或文件>`
- 禁止执行：`<建库、删库、安装、提交、推送等>`
- 禁止新增：登录权限、JWT、Redis、TDengine、微服务、实时数据接入、复杂预测分析及其他未冻结能力。
- 不得把未实现、未执行或未验证内容写成已完成。

## 5. 输入与契约

### 前端任务

- 页面或组件：`<名称>`
- 调用接口：`<Method + URL>`
- 请求字段：`<字段、类型、必填、格式>`
- 响应字段：`<字段、类型、单位>`
- 状态：`加载 / 成功 / 空数据 / 失败`

### 后端任务

- 接口：`<Method + URL>`
- Request：`<参数与校验>`
- Response：`<JSON 结构>`
- 业务规则：`<唯一性、关联、数值范围等>`
- 分层边界：Controller 不直连 Mapper，业务校验放在 Service。

### 数据库任务

- 目标表：`<四张核心表之一>`
- DDL 依据：`<设计文档路径>`
- 约束与索引：`<需验证的项目>`
- 数据准备：`<济南/青岛/烟台/潍坊/临沂/济宁、ECMWF/NOAA、T2M/PRECIP 等>`
- 回退与数据保护：`<执行前确认和恢复方式>`

### 文档任务

- 文档受众：`<开发/检查/验收/答辩>`
- 事实来源：`<现有文件或实际验证结果>`
- 必须同步：`<导航、状态或关联文档；没有则写无>`
- 状态措辞：明确区分已完成、已设计、待执行。

### 测试任务

- 测试对象：`<接口/页面/数据库/端到端>`
- 环境：`<版本与配置前提>`
- 数据：`<固定测试数据>`
- 预期结果：`<可判断的结果>`

## 6. 测试与验证

- 必须运行：`<直接相关的测试或检查>`
- 建议运行：`<条件允许时的扩大验证>`
- 核心用例：`<正常、空结果、边界、错误输入>`
- 证据：`<命令输出、截图、响应或检查记录>`
- 若未运行：写明“未运行”及具体原因，不得声称通过。

## 7. 验收清单

- [ ] 目标结果已经实际产生。
- [ ] 只修改允许范围内的文件。
- [ ] 未改变冻结技术栈、三大模块、四张核心表和业务唯一键。
- [ ] 接口、数据库和前端字段保持一致。
- [ ] 相关测试或检查已运行并记录结果。
- [ ] 未运行项已明确说明原因。
- [ ] 没有真实密码、令牌、本机私有配置或不必要绝对路径。
- [ ] 文档未将规划或草案描述为已实现。

## 8. Git 要求

- 建议分支：`feat/* / fix/* / docs/* / test/*`
- 建议提交信息：`<type>(<scope>): <summary>`
- 提交前检查状态，仅暂存本任务具体文件并检查暂存差异。
- 默认禁止无检查执行 `git add .`。
- 禁止破坏性 Git 操作、强制推送和擅自覆盖用户改动。
- 是否允许创建分支：`是 / 否`
- 是否允许提交：`是 / 否`
- 是否允许推送：`是 / 否`

## 9. 完成报告

按以下顺序输出：

1. 完成内容。
2. 修改文件。
3. 验证结果。
4. 未运行检查及原因。
5. 范围与 Git 操作确认。
6. 剩余事项或阻塞。

## 10. 简短示例

- 任务编号：`BACKEND-QUERY-1`
- 目标：按城市、模型、要素和时间范围返回预报记录，供表格与图表共同使用。
- 允许修改：后端查询相关 Controller、Service、Mapper、DTO、VO 和对应测试。
- 禁止修改：数据库表结构、前端页面和冻结需求。
- 契约：`GET /api/forecast-records`，参数为 `cityId`、`modelId`、`elementId`、`startTime`、`endTime`。
- 验收：覆盖正常查询、无结果、非法时间范围和缺少必填参数；未运行的数据库集成测试必须说明原因。
