# 最终验收方案与 Demo V2

## 1. 状态与准备

计划软件验收 2026-09-18，材料归档 2026-09-25；A/B 共同执行。本页是验收方案，当前未运行任何业务测试，不能据此认定软件完成。

后续准备授权演示环境：Vue、Spring Boot、MySQL 四表，16 山东城市、ECMWF/NOAA、T2M/PRECIP、约 7 天演示窗口；地图资源合法且映射完整。济南/青岛具有可核对的多时刻记录。记录实际版本、数据来源/窗口与环境，不展示密码。

## 2. 固定十二步 Demo

| 步骤 | 操作 | 观察 / 通过条件 |
| --- | --- | --- |
| 1 | 打开系统 / | 自动进入 /weather 山东气象工作台 |
| 2 | 默认 ECMWF + T2M | 16 市温度分布、图例、时间和单位正确 |
| 3 | 点击济南 | 详情显示当前温度、模型、要素、时间、单位 |
| 4 | 拖动底部时间轴 | 地图颜色与济南值同步变化；Network 无新增 API 请求 |
| 5 | 切换 PRECIP | 降水图层与图例/单位同步，必要时一次批量加载 |
| 6 | 点击“查看趋势” | 携带城市/模型/范围到 /analysis；温度折线、降水柱状、最高/最低/平均温、累计降水及明细表 |
| 7 | 进入模型对比，济南 + T2M | ECMWF/NOAA 双折线；再切 PRECIP 检查分组柱状 |
| 8 | 进入数据管理 | 城市、模型、要素、记录四 Tab；分别说明并演示 CRUD（临时字典数据） |
| 9 | 新增或修改 ForecastRecord | 显示成功，刷新列表；记录本次 id、业务键和保存值 |
| 10 | 重新进入趋势并查询对应范围 | 表格/图表/统计反映新数据；缓存未复用旧值 |
| 11 | 重复业务键；非法时间范围 | 分别真实 HTTP 409、400，友好提示且没有错误写入 |
| 12 | 验收结束 | 汇总证据、遗留项和实际结论，不以演示结束替代通过判定 |

步骤 6/7 补做青岛城市切换，验证状态、图表和单位同步；步骤 5 可演示 ECMWF → NOAA → ECMWF 相同范围的缓存命中。
