# 山东气象课程系统：离线演示

## 准备条件

Windows 10/11 x64、Windows PowerShell 5.1、现代浏览器，本地可写文件夹及充足磁盘空间（建议至少 5 GB）。需要 Microsoft Visual C++ 2015–2022 x64 运行库；脚本会检查，缺少时按提示由用户安装，不会静默安装。组织策略若禁止 PowerShell 脚本，请联系管理员，不修改系统策略绕过管理。

Java 17 与 MySQL 8 已随包提供；目标电脑无需全局 Java、Maven、Node 或 MySQL 服务。本系统使用合成课程演示数据，不是实时气象服务，也不是生产部署。仅本机访问，不对外公开管理接口。

## 启动

完整解压后双击 `启动演示.cmd`，不要在 ZIP 内直接运行。支持文件夹名含空格；建议路径简短，避免 OneDrive/网络共享/受保护目录。新认证版脚本依次等待独立数据库、应用与临时USER会话的真实字典查询成功，退出探测会话后打开 http://127.0.0.1:18080/login 。请保留启动窗口，使用停止入口退出。四页从顶部导航进入，默认演示日期为 2026-09-07 08:00～14:00。

公开课程账户：普通用户 `demo_user` / `DemoUser@2026`，管理员 `demo_admin` / `DemoAdmin@2026`。**DEMO ONLY / NOT FOR PRODUCTION**，不是数据库连接密码；选择对应入口。USER仅展示页，ADMIN另可管理。旧v1.0 ZIP无登录，不自动升级，本阶段不重制完整ZIP。

## 停止

双击 `停止演示.cmd`，等待应用和数据库正常退出再移动文件夹或关闭电脑。只停止本包核验过的进程；若无法核验或关闭超时会报错，不会结束其他 Java/MySQL 程序。勿同时重复点击启动。

## 首次初始化

AUTH-ROLE-1 新构建必须携带 schema.sql → data.sql → auth-data.sql，按顺序首次导入；4张气象表+sys_user认证表。初始化账号仅哈希入库。禁止复用旧var覆盖初始化；旧目录缺认证表时启动探测将失败并保留现场，不自动清空/迁移。若手动变更固定探测USER账户，需由维护者同步启动方案，不能以开放匿名字典绕过。

仅首次启动在包内 `var/` 建立独立数据库，导入随包Schema/Seed。已发布v1.0 ZIP仍为16/2/2/192；当前源码data.sql扩展为16/2/6/46,080、240时次，下一版构建继续自动复制此SQL。MONTHLY-SYNTHETIC-DATA-1已用原初始化脚本在新隔离目录验证导入，不重制完整ZIP，不自动迁移旧var目录；不得覆盖旧运行数据后重新初始化。生成演示专用随机凭据保存在 `var/private/`，应用账号只有演示库CRUD权限，不使用开发机密码。

后续启动保留数据，不重复导入。不要把运行后的 `var/`、日志或密码再发给别人；分发原始干净 ZIP。不要手动删除部分初始化目录来重试；失败时先停止并保留现场给维护者检查。

## 常见故障

- 13306 或 18080 已占用：启动停止并提示；自行关闭确认不用的程序或另择演示电脑，脚本不会杀占用者。
- 缺少运行库/浏览器：按清楚提示手动准备；不保证所有 Windows 电脑绝对零系统依赖。
- 脚本策略/杀毒拦截：确认来源与校验值，依组织规定处理；启动只设置本次 PowerShell 进程参数，不修改全局执行策略、防火墙或环境变量。
- 初始化失败、状态不完整、数据目录已存在但没有完成标记：停止，不自动删目录或重复导入；检查包内日志，不公开私有配置。
- 文件夹名无法用系统 ANSI 编码表示：改用较短的英文目录名；不要强行跳过配置编码检查。
- 首次启动可能需要较长时间；就绪以真实字典查询为准，不仅是健康接口。
- 页面无法打开：确认启动成功，使用 127.0.0.1:18080 而非开发端口；有问题看 `var/logs/`。无需访问互联网，地图/脚本/样式均在包内。
